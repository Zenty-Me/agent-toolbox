## 3.5 模型怎样把分数变成概率？

假设图片里只有一种动物，模型要从“猫、狗、兔子”中选一个。我们用这个例子理解 logits、softmax 和温度。

<a id="ch03-softmax-logits"></a>

### 1. logits：模型给出的原始分数

模型先给三个候选打分：

| 候选 | 分数 |
| --- | ---: |
| 猫 | 0 |
| 狗 | 1 |
| 兔子 | 2 |

这组 `[0, 1, 2]` 就叫 **logits**。兔子分数最高，表示模型更偏向兔子。

但分数不等于概率：2 分不是 2%，分数也可以是负数。我们还需要把它们转换成概率。

<a id="ch03-softmax-calculation"></a>

### 2. softmax：把分数变成概率

softmax 的计算可以分成三步：

1. **求指数**：`[0, 1, 2]` 变成约 `[1, 2.718, 7.389]`。这能让结果都为正，同时保留分数的高低顺序。
2. **加起来**：`1 + 2.718 + 7.389 = 11.107`。
3. **各自除以总和**：得到约 `[9.0%, 24.5%, 66.5%]`。

例如兔子的概率就是 `7.389 ÷ 11.107 ≈ 66.5%`。三个概率加起来是 100%，这组结果就是一个**类别概率分布**。

公式表达的也是这件事：

$$p_i=\frac{e^{z_i}}{\sum_j e^{z_j}}.$$

其中 $z_i$ 是某个候选的分数；分子是它的指数值，分母是所有候选指数值的总和。

如果给所有分数都加 100，概率不会变：指数值都乘上了同一个倍数，除以总和时会抵消。所以 softmax 看重的是**分数之间的差距**。

<a id="ch03-softmax-temperature"></a>

### 3. 温度：控制概率有多集中

温度的做法很简单：**先把 logits 除以温度 $T$，再做 softmax**。这里 $T>0$。

- **$T=1$**：分数不变，兔子的概率约为 **66.5%**。
- **$T=0.5$**：分数变成 `[0, 2, 4]`，差距拉大，兔子的概率升到约 **86.7%**。
- **$T=2$**：分数变成 `[0, 0.5, 1]`，差距缩小，兔子的概率降到约 **50.6%**，猫和狗获得更多机会。

因此，低温让概率更集中，高温让概率更均匀。温度改变的是概率分配，不保证答案更正确。

<a id="ch03-softmax-choice"></a>

### 4. 有了概率，怎么选答案？

有两种常见方式：

- **argmax**：直接选概率最大的，本例就是兔子。
- **随机采样**：按概率抽一个。兔子最容易被抽中，但猫和狗也有机会。

温度会改变采样的机会；如果始终用 argmax，本例调整正温度后仍然选兔子，因为分数的高低顺序没变。

大模型预测下一个 token 时，也会用到这条流程：模型先打分，softmax 给出概率，再按选择规则生成结果。

如果任务允许多个标签同时成立，例如图片里既有猫又有狗，通常分别用 **sigmoid** 预测“有没有猫”“有没有狗”。这时两个概率不必加起来等于 100%。
